# MUICT Club Registration

Browse ten MUICT student clubs, read what each one does, and register in the browser. Your name, student ID, and memberships stay in local storage on this device.

Clubs: AI, Dev, IoT, Cyber, Badminton, Table Tennis, Japanese Society, Board Game, Media and Entertainment, and Speakers.

## Run

```bash
npm install
npm run dev
```

Open the URL Vite prints, usually http://localhost:5173.

## Test

```bash
npm test
```
